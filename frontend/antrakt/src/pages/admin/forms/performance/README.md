# Внутренняя структура формы спектакля

Согласовано с владельцем: меняется организация кода, внешний вид и поведение
создания/редактирования остаются прежними. Публичный импорт `PerformanceForm`
из `../PerformancesForm.tsx` сохранён. Базовая форма — тот же Modal в родительской
странице, две колонки, те же поля, стили и порядок. Новых панелей, вкладок,
закреплённых кнопок, правил проверки или сохранения не добавлено.

- `../PerformancesForm.tsx`: только компоновка, подсказка обязательных полей,
  две прежние колонки, действия и окно загрузки галереи.
- `usePerformanceForm.ts`: общее состояние, справочники актёров/режиссёров,
  обработчики, создание/редактирование и уведомления. API URL и методы прежние.
- `data.ts`: прежняя нормализация исходной записи, локальное время показов,
  формат подписей дат, подготовка nullable-полей payload.
- `types.ts`, `options.ts`: типы формы, значения пунктов «Другой», жанры,
  возрастные ограничения и коллективы.
- `presentation.tsx`: прежние цвета, Chakra-иконки и Motion-компоненты.
- `MainFields`, `DirectorFields`: поля левой колонки и данные постановки.
- `PerformanceImageField`: одинаковая разметка загрузки постера/фото с нужным полем.
- `ProductionTeamField`, `ShowsField`, `CastField`: команда, показы/билеты, состав.
- `GalleryField`, `GalleryUploadModal`, `DescriptionField`, `FormActions`:
  галерея, прежнее окно загрузки, описание и нижние кнопки.

Секции получают типизированный `form`. Компоненты объявлены на уровне модулей,
чтобы при вводе данных не пересоздавались типы компонентов и не терялся фокус.
Секции возвращают исходные элементы/React fragments без новых DOM-обёрток,
сохраняя работу spacing двух VStack. Связь данных спектакля и обработка ошибок
сервера не менялись. Backend и его автоматизация этим рефакторингом не затронуты.

Проверки: usePerformanceForm.test.tsx проверяет создание с показами/билетами,
актёром, режиссёром и гостем, галереей; обновление с сохранением ID и местного
времени; сохранность данных при ошибке. Дополнительно одинаковый Chromium-сценарий
выполнен до и после: HTTP payload совпадает полностью; снимки создания и двух
частей редактирования совпали пиксель в пиксель. API и изображения в браузерной
проверке подменялись синтетическими ответами, реальные данные и MinIO не менялись.
